뷰티로그 멀티페이지 Streamlit 앱 실행 방법

1. 이 폴더에서 터미널(명령 프롬프트)을 엽니다.
2. 아래 명령어를 차례대로 실행합니다.

python -m pip install -r requirements.txt
python -m streamlit run app.py

페이지: 홈, 화장품 보관함, 유통기한 관리, 루틴 체크, 소비 분석, 위시리스트
화장품 등록 시 개봉 여부, 개봉일, 개봉 후 사용기한 날짜를 입력할 수 있습니다.
개봉 후 사용기한이 내일 끝나는 제품은 앱 상단과 관련 페이지에 경고로 표시됩니다.
데이터는 이 폴더의 beautylog_data.json에 저장됩니다.
